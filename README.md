# ✨ Arpitha Jain — Portfolio

Welcome to my personal portfolio website!  
A modern, responsive space to showcase my skills, projects, internship experience, achievements, hackathons, and academic journey. 🚀

## 🌐 Live Demo

🔗 Visit My Portfolio:  https://arpitha-jain-s-portfolio-42ez.vercel.app/

## 🌟 Highlights

- 💫 Animated hero section with a typewriter name effect
- 🖼️ Floating circular profile image with glowing animations
- 🎬 Smooth scroll animations using AOS and Framer Motion
- 💻 Projects, technical skills, and development journey
- 🏢 Infosys Springboard internship showcase
- 🏆 Connected milestones and certifications section
- 🥇 Hackathons, gallery, education, and achievements
- 📄 Resume download and social media links
- 🌙 Responsive dark-themed design

- 
## 🛠️ Tech Stack

- ⚛️ React 19
- ⚡ Vite 8
- 🎨 Tailwind CSS 4
- 🎭 Framer Motion
- 🌊 AOS — Animate On Scroll
- 🧩 React Icons

- Node.js 20 or later
- npm

📁 Project Structure

  components/       # 🧩 Portfolio sections

📄 Replace public/ArpithaJain_Resume.pdf to update the resume
📷 Add gallery images inside public/events/
🎭 Customize colors, animations, and fonts in src/index.css
